新增 [packages/](packages/)：主程序实际依赖的四个功能核心包与共享 SDK，支持独立分析、测试。详见该目录说明。

# 学无止境插件源码与示例

本目录准备作为独立的插件 GitHub 仓库发布，采用本目录的 MIT 许可。`plugins/plugins.json` 是可供现有应用插件中心安装的声明式示例索引。

`source/` 包含四个随主程序提供的功能源码：讲解画板、词语收录本与词典、积分与花样积分、挑战模式。它们当前依赖主程序中的数据库、题目模型、主题、配置和其他接口，不能作为独立 Flutter 包编译，也不能通过声明式插件中心动态安装。要构建这些功能需要匹配版本的主程序开发环境；仓库并不提供主程序源码或构建产物。

现有外部插件协议仅支持 JSON 工作页与计分规则，不支持加载任意 Dart 代码。未来拆分为独立插件 SDK 或可动态安装模块需要另行开发。请不要把 `source/` 中的文件当作现有插件索引中的可安装条目。

用户数据、题库、账户信息、构建密钥及发布文件不应加入此仓库。发布前应审查文件和提交记录。
